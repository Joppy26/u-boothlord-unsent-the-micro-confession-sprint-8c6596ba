A tiny Python program that writes one two-part micro-confession — a `To:` line and the unsent message itself, exactly as it was typed — to `entry.txt`.

Run it with `python3 main.py`. It writes to `$MAKEFUN_OUTPUT_DIR` (or `/output` by default) and produces byte-identical output on every run.
